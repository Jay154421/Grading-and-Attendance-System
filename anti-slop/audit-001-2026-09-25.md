# Anti-Slop Audit 001

Date: 2026-09-25
Scope: sidebar redesign (Sidebar.jsx, teacher-layout.jsx, student-layout.jsx, index.css)
Mode: AFTER (audit first, fix only approved numbers)

Verification evidence so far:
- `npm run lint` passes (0 errors)
- `npm run build` passes (vite build, all modules transformed)
- Vite dev server serves index + all 3 touched modules with HTTP 200 (transform errors would return 500)
- Code inspection of every interactive element (see finding 3 for the gap)

## Findings

1. [HIGH] R-03 (Hard Gate) Mobile tap targets are under the 44px minimum.
   Header hamburger button has no padding (24px icon only); drawer close,
   logout, and nav items are ~36px tall (py-2 + 20px line box).
   Where: teacher-layout.jsx header button, student-layout.jsx header button,
   Sidebar.jsx (NavItem, LogoutButton, close button).

2. [HIGH] R-32 (Hard Gate) Drawer does not manage focus.
   When the mobile drawer opens, focus stays on the hamburger behind the
   backdrop; Tab then moves into the page content underneath the overlay.
   No focus move into the drawer on open, no focus restore on close.
   Escape close is implemented and works.

3. [HIGH] R-35 (Hard Gate) Browser click-through not performed.
   Build + dev-server transforms + code inspection passed, but no real browser
   was driven to click each control (no browser tool in this environment).
   Manual click-through still required before shipping: nav links, active
   states, collapse toggle, drawer open/close/backdrop/Escape, logout.

4. [HIGH] R-27 (Hard Gate) TeacherLayout renders `null` while the session
   loads (pre-existing code, but the file was touched in this change).
   No loading indicator. StudentLayout has no loading indicator either.

5. [LOW] R-31 / R-37 (Quality Lock) Design direction and one-line decision
   reasons exist only in this chat. No DESIGN.md in the repo records the
   direction (modern light sidebar, red brand accent) or the reasons for
   color/layout/motion choices.

Not flagged (passes):
- R-02 no em dashes in UI text; R-24 all nav items point to real routes;
  R-26 every control has real behavior (NavLink, toggle, drawer, logout);
  R-25 contrast checked (gray-500 on white 4.83:1, red-700 on red-50 ~5.7:1,
  gray-600 on white ~7:1, all AA pass); R-29 palette = neutrals + one accent
  (red); R-19 drawer slide has a written purpose (spatial orientation),
  no loops; R-17/R-18/R-36 no fabricated numbers or testimonials.
